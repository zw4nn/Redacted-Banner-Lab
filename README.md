# Redacted BannerLab

**Create. Plan. Share. Go further.**

Redacted BannerLab est une application Android pensée pour les Agents Ingress afin de préparer, créer et gérer des bannières et parcours, avec des outils complémentaires regroupés dans le Lab.

## Fonctionnalités

- Création et préparation de bannières et de missions
- Recherche et outils liés aux missions Ingress
- Gestion des images et calques
- Intégration avec IITC via **IGOR — IITC Gateway for Operations & Routing**
- Actualités officielles Ingress dans la chambre de RITA
- Notifications Android des nouvelles publications Ingress
- Outils Scanner / REDACTED et contenus du Lab
- Interface multilingue
- Application mobile Android, avec architecture pensée pour une évolution web

## RITA

**RITA — Robot d’Investigation, de Transmission et d’Analyse** accompagne Redacted dans le Lab.

Elle peut notamment surveiller les actualités officielles Ingress et signaler les nouvelles transmissions. Certains événements peuvent également disposer de contenus complémentaires directement dans l’application.

## IGOR

**IGOR — IITC Gateway for Operations & Routing** assure le lien entre Redacted BannerLab et IITC pour les fonctions compatibles.

## Installation

Les APK officiels sont produits par le workflow de build du dépôt. Les clés de signature et secrets de production ne sont pas stockés dans les sources.

Pour une mise à jour Android, conserver l’application installée et utiliser un APK signé avec la même clé que les versions précédentes.

## Confidentialité et transparence

Le projet vise à limiter les traitements aux fonctions nécessaires à l’application. Les intégrations externes utilisées par une fonctionnalité sont identifiées dans le code et les notices du projet.

Aucune clé privée, aucun mot de passe de signature et aucun secret de production ne doit être ajouté au dépôt.
